<objective>
Make the typed Board Length box wide enough to show its own number.

In plain English: a shaper on Metric types their board's length into a small box above the Board
Length slider — `188.0 cm`. The box is too narrow for that text, so the last character or two is
cut off, on the Template Builder, the Volume screen and the Fins screen. Widen the box at those
three sites, and leave the ROCKER datasheet's little typed cells exactly as they are, because they
only ever hold a short bare number and they sit in a table with no room to spare.

This closes UAT gap G-06-4. The box inherited its 64px width from the retired `ImperialField`,
which only ever showed short bare fractions inside the datasheet; the reuse was justified — in the
UI-SPEC, in plan 06-02 and in the code comment — by counting characters (8 is fewer than 9). The
debug session measured the real thing in the app's own Inter font at 14px: `188.0 cm` renders
59.4px and `365.0 cm` renders 62.0px, against a box that leaves 50px of room for text. So 9 to
13px of every metric length is clipped, at every value in range.

Purpose: a number a shaper cannot fully read is worse than no number — they cannot tell `188.0`
from `188.9` when the box eats the end of it.

Output: a field whose width follows its render mode, a source-contract test that pins both widths
and names which mode each belongs to, and a UI-SPEC that records measured widths instead of a
character count.
</objective>

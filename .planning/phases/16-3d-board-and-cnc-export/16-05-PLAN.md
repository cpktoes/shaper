<objective>
Write the CNC files from the board's surface: one zip holding a DXF wireframe, the XYZ text set and an STL — the bare
board, in millimetres, in Shape3D's axes, named from the board's name — each format with its own reader for the tests.

Everything here is pure and dependency-free (research §D, §E): an R12 ASCII DXF of 3D polylines, a binary STL of the
very triangles the surface carries, plain `x y z` text, and a store-only zip with CRC-32. `cnc-files.ts` builds the
file list from one surface (16-03) and returns the slice count the screen's done line will quote. The board file's
name-cleaning is lifted into one shared stem so the two downloads never name a board differently. The founder gets the
four presets' zips to open in Shape3D's trial if he wants, and a picture of what is inside them.

Purpose: R7 (the export's contents), R8 (the files Shape3D takes), R12. Decisions D-14, D-16, D-24, D-26.
Output: `lib/export/` (four formats + the assembly), `boardFileStem`, tests, a picture.
</objective>

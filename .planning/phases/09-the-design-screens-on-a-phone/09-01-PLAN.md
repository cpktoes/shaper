<objective>
Put the measuring tape in the drawer before we start cutting.

This plan installs Playwright (the tool that drives a real browser for us), then takes a picture of
all five design screens as they look on a desktop today, and writes one automated test that drags
the outline and rocker points with a mouse and proves they still move. Nothing about the app
changes. From here on, every phone change in this phase has to leave those five desktop pictures
and that mouse drag exactly as they are — that is what "desktop untouched" (PHON-05) means, and
this plan is what makes it a measurement instead of a promise.

Purpose: TEST-01's harness, and the "before" evidence the whole phase is judged against.
Output: `playwright.config.ts`, two spec files, five committed baseline images, two npm scripts.
</objective>

## Executor environment — read this first

Measured on 2026-09-08; these trip executors otherwise.

- You work in a git worktree under `.claude/worktrees/`. `npm test` and `npx tsc --noEmit` work
  there because Node walks up to the main checkout's `node_modules`. **Turbopack does not walk up.**
  `npm run dev` and `npm run build` both fail in a fresh worktree with
  `Could not find the Next.js package (next/package.json)`, and symlinking the parent's
  `node_modules` in fails too (`Symlink [project]/node_modules is invalid, it points out of the
  filesystem root`). The fix, measured: run `npm install --no-audit --no-fund` once inside the
  worktree — it took 17 seconds — after which `npm run dev` starts and serves normally.
  Task 1 does this explicitly.
- `.env*` files are blocked for you and you do not need them. Every `/design/*` route is open to a
  signed-out shaper (`proxy.ts` calls no `.protect()`), so the Playwright `webServer` block carries
  its own obviously-fake Clerk and database values. Verified: with those fakes and no `.env.local`
  at all, `GET /design/outline` returned 200 and rendered the board.
- A bare `tsc` in a worktree can report phantom `LayoutProps` errors. Ignore those specific ones;
  use `npx tsc --noEmit`.
- The real `npm run build` runs on `main` after merge, not here. Do not try it.
- `worktree.cleanup-wave` refuses file deletions. No task in this phase deletes a file.
- `workflow.human_verify_mode` is end-of-phase: never stop for a human. Put anything a person must
  look at in the SUMMARY under "Human verification deferred to end-of-phase UAT".
- Branded values (`Mm`, `Litres`, `Degrees`) must be built with `mm()`/`litres()`/`degrees()` even
  in tests — vitest does not type-check.

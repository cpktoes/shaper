Write down, to the last decimal, every number the app shows today — before anything about the curves changes.

numbers, and the four preset cards must not move by more than 0.015" at a station. All of that needs a trustworthy
"before". This plan records it the way Phase 12 recorded Phase 11's numbers: a script runs today's own maths (the
code live on the site, commit `ed39f4a`) over every blank's three curves, the four presets, the first board a visitor
sees, a slice of the test boards and the hidden-station data the curve test needs, and writes them to a file. The
blanks it uses are copied into that file by value, so a later catalogue correction can't move a recorded number.
Two tests prove today's code reproduces the file exactly.

Nothing a shaper sees changes in this plan.

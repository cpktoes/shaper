  <how-to-verify>
    Walk it the way a shaper would, start to finish.

    **The volume is live (VOL-01)**
    1. Run `npm run dev`, open http://localhost:3000, and start or open a board.
    2. Go to the Volume screen and note the litres figure.
    3. Go to the Template screen, drag a control point or widen the widepoint, then go back to Volume. The litres figure should have changed to match — no reload, no stale number.
    4. On the Volume screen, confirm the card still says which method produced the number (whether it is using your drawn outline's area or the area factor). A number that does not say where it came from is the one thing this phase should not ship.

    **The math is proven (the CI gate)**
    5. Open the repository's Actions tab on GitHub. There should be a CI run for this phase's branch, green, running the geometry suites, lint and a build.
    6. Optional but worth it: break one geometry expectation locally, push, and confirm the run goes red. Then undo it. A gate nobody has seen fail is a gate nobody should trust.

    **The template (TMPL-01)**
    7. On the Template screen, press Export Template. Check the preview: page count, tile diagram, Letter selected by default. Switch to A4 and back.
    8. Download the PDF. Print the first page at 100% with "Fit to page" off, and measure the 2-inch square with a ruler. It must be exactly 2 inches.
    9. Print the rest, cut, and tape a few pages together along the overlap using the match marks. The curve should run continuously with no step at a join.
    10. Confirm the finished template carries: the four marks and only those four (nose 12", tail 12", centre, widepoint — no every-12-inch ladder); the board name and dims inside the part you keep; and the how-to box on the nose page.
    11. Rename the board to something very long, export again, and confirm the name truncates rather than running over the drawing. Then clear the name entirely and confirm it prints "Untitled Board".
    12. Repeat the export from the Summary screen — same button, same dialog, same file.

    **The screens**
    13. On the Template screen, exercise the four toolbar buttons: rotate, export, construction lines, wide view.
    14. On the Summary screen, print-preview the order form on a default board and on a 25-inch board.

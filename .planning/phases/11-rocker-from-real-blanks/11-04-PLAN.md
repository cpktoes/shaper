<objective>
Give every screen one description of the board's side — whether it sits in a real blank or is still
hand-set — and move the existing foil onto the same maths.

Three things land here, all pure:

1. **The hand-set fallback rocker (D-14).** A board with no blank gets five typed rocker stations —
   nose tip, nose 12", centre (zero), tail 12", tail tip — drawn through pchip. The old three-knot curve
   stays in the file only so that boards saved before this phase can be converted to five stations when
   they reopen (plan 11-09 wires that).
2. **One side profile (Pattern 5).** `BoardSideProfile` answers "how high is the bottom and how thick is
   the board at any point along it", plus the four rocker numbers, the five thicknesses RAILS reads, and
   — when a blank is picked — the blank's own silhouette, the foam to come off at each station, and the
   blank's own numbers for the DATASHEET. Built once; drawing, volume, rails and the Summary all read it.
3. **The foil on pchip (D-13).** `sampleFoil` switches to the new sampler, and the cross-section volume
   can take the profile's dense thickness curve, so a blank-derived foil is integrated as drawn rather
   than re-splined from five points. The default board's litres move by a hair — 29.79 to 29.94 — which
   is why the VOLUME desktop screenshot is re-recorded later in the phase (plan 11-12).

Output: `rocker.ts` additions, `lib/geometry/board-profile.ts`, `foil.ts` on pchip, an optional
`thicknessAt` on the volume input; tests.
</objective>

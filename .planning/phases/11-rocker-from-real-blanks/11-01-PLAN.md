<objective>
Teach the app the maths of a real foam blank, and prove it against the catalogues before anything on
screen changes.

This is the phase's first slice, and it is deliberately all arithmetic. It reads the three vendor
catalogue tables straight from `db/seed/blanks/`, turns every station into millimetres at the units
boundary, fits each blank's rocker, thickness and width with textbook pchip (the same monotone spline
SciPy and MATLAB use, so no curve ever invents a hump between two catalogue stations), levels the
rocker so the low point reads zero, lays a board of any length on the blank at any placement, scales
the blank's own foil down to the board's centre, eases the ends into the shaper's tip settings, and
checks the fit at every point — thickness and width.

The first task is a thin end-to-end tracer: one CSV file, through the reader, through pchip, through
the levelling, to the four rocker numbers of the brief's reference board (Marko 6'0" M-Regular at full
length, placement 0: nose 4.12, nose 12" 1.32, tail 12" 0.56, tail 1.74). If that path is wrong,
nothing built on it can be right, so it is proven first.

All four of the brief's named tests land here, in wave 1, before any screen file is touched (R16).

Purpose: R3, R4, R7–R14, R16 and decisions D-05, D-08, D-10, D-11, D-13, D-17, D-18.
Output: `lib/geometry/pchip.ts`, the CSV reader and catalogue mapping under `lib/blanks/`, the blank
types, the core of `lib/geometry/blank-fit.ts`, and their tests.
</objective>

<objective>
Let a shaper's fit and tip defaults live on their account, so they follow them to any device.

The five numbers — Extra Length (2"), Extra Center Thickness (3/8"), Width Margin (1"), Nose Tip
(5/16"), Tail Tip (1/4") — get five empty-by-default columns on the existing preferences row, a
migration applied to the development database, a read that fetches only those five, a server-side
resolver the root layout will call so the very first paint shows the right numbers, and one Server
Action that saves them. Every piece copies the Imperial/Metric setting exactly: the session decides
whose row is written, a signed-out shaper's choice lives in their browser, and a database that has not
been migrated yet never breaks a page.

The gear-menu row and dialog that use this arrive in plan 11-08.

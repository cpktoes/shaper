<objective>
Work out each board's real turn as plain, tested maths.

At rest a board on the rack stands on its tail showing its side profile; as it turns, each of 65 stations along
the board is drawn at the turn angle from the board's own rocker, thickness and half-width, so the picture is
exactly the side profile at 0 degrees and exactly the TEMPLATE outline at 90 degrees, a swallow's notch included,
with the stringer sliding from the rail edge to the centre. This plan writes that maths (`lib/geometry/rack-art.ts`),
the one shared recipe for a saved board's side profile (`designSideProfile`), and the server-side rule that leaves
out a board whose picture can't be worked out, reporting it by id for the go-live check (D-13).

Purpose: R1, R3, SPEC constraints 1 and 3, WR-05; feeds the phase's tracer (15-06) and the D-13 report (15-08).
Output: `lib/geometry/rack-art.ts` and its tests, `designSideProfile`, `rackBoardFigures`, `rackModelsAndDrops`.
</objective>

New shapes this plan creates (15-02's tests, 15-05, 15-06, 15-08 and 15-12 import these names exactly):
- `RACK_ART_STEPS = 64`; `RACK_OUTLINE_SWITCH_RAD = 1.562`.
- `interface RackStation { station: Mm; rocker: Mm; deck: Mm; half: Mm }`
- `interface RackBoardArt { length: Mm; stations: readonly RackStation[]; tMid: number; maxDeck: number; maxHalf: number; silhouette: readonly { station: number; w: number }[] }` (all millimetres; `tMid = maxDeck / 2`; 65 stations, tail 0 to nose `length`).
- `interface RackPoint { station: number; x: number }` (millimetres; x across the board from its turning axis, positive toward the deck at rest).
- `buildRackBoardArt(profile: BoardSideProfile, geometry: OutlineGeometry, steps = RACK_ART_STEPS): RackBoardArt` — throws an `Error` naming the first non-finite value.
- `turnedBoardPoints(art, theta: number): RackPoint[]` (closed polygon: right edge tail to nose, then left edge nose to tail; from the switch angle up, the silhouette mapped x = -w).
- `turnedBoardPath(art, theta, scale: number, cx: number, floorY: number): string` (screen x = cx + x * scale, y = floorY - station * scale, through `polylinePath(..., true)`).
- `stringerPoints(art, theta): RackPoint[]` (x = (deck - tMid) * cos theta) and `stringerPath(art, theta, scale, cx, floorY): string` (open polyline).
- `halfExtent(art, theta, scale): number` = sqrt((maxDeck * scale / 2 * cos theta)^2 + (maxHalf * scale * sin theta)^2) — a spacing figure for the room the rack makes.
- `drawnSpan(art, theta): { left: number; right: number }` — the min and max x of `turnedBoardPoints(art, theta)`, millimetres.
- `spineAnchorX(art, theta, scale, fontSize, gap = 4): number` — dots from the board's axis to the baseline point of its rotated words.
- `LIVE_DESIGN_RULES: DesignRules` (`{ prepare: prepareBlank, handSetCurve: "root" }`); `designSideProfile(fields: Pick of DesignSummaryFields "outline" | "rocker" | "foil" | "blank", rules: DesignRules): BoardSideProfile`.
- `interface RackBoardFigures { summary: DesignSummary; art: RackBoardArt }`; `rackBoardFigures(fields: DesignSummaryFields): RackBoardFigures` (throws when the summary or the art can't be worked out).
- `interface RackModelsResult { models: RackModel[]; dropped: string[] }`; `rackModelsAndDrops(rows, log?, options?): RackModelsResult`.

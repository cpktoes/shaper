<objective>
Make a practice rack the browser tests can use, that can never appear on the live site, and photograph today's rack.

The browser tests run signed out with no database, so they can never see a saved board. This plan adds a test-only
page, `/test-rack`, that shows the real home screen with stand-in boards built from the app's own presets — one,
fifteen or thirty of them, a swallow, hand-set boards, a long name — switched on only by a flag in the test
server's settings and provably dead in a production build. It also captures "before" pictures of today's card grid
with fifteen boards on a computer and an iPhone, for the founder's go-live comparison.

Purpose: makes R5, R6 and R8 testable in a browser (RESEARCH Pattern 8); before pictures for D-10's go-live.
Output: the stand-in module and route, the test flag, a dev spec, a production-build spec, two pictures.
</objective>

<objective>
Put the Thinning Starts controls on ROCKER — one for the nose, one for the tail — working end to end.

With a blank picked, THICKNESS ends with Tip Style and then two sliders, each with the distance in its label, a line
saying whether it is "Picked automatically" or set by hand, and an Automatic button that puts it back. Dragging sets
that tip's start by hand (one undo step per drag); Automatic is one undo step; switching blanks keeps a start set by
hand; ↺ Reset Fine-Tune leaves the starts alone. If a start set by hand is too close to its tip, one sentence in
warning ink under its slider says where the board is thinnest and that Automatic would clear it. The THICKNESS
opening line and the 12" rows' hints change to match. Browser tests prove it on a phone and a computer.

</objective>

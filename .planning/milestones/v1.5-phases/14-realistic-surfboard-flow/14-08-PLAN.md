<objective>
Write the tips step's maths — where each tip's thinning starts and the steady taper from there — as one small pure
module, proven on its own before any board uses it.

A board's thickness will run down steadily from a start point to the tip setting, along one smooth curve that leaves
the planer cut along its own slope (the shape the founder picked from the three in the picture). The start is 12"
unless the board can't run down steadily from there; then Automatic looks further in, half an inch at a time, and
takes the first point that can. A start the shaper sets by hand is honoured exactly and, if it is too close to the
tip, flagged with where the board is thinnest. This plan writes all of that, plus the one thing it needs from the
curves — their slope — and proves it. Nothing on screen changes yet.

Purpose: R6, R7; D-01 to D-05, D-07, D-21, D-23, D-28.
Output: `slopeAt` on both curve kinds, `lib/geometry/tip-taper.ts` and its tests.
</objective>

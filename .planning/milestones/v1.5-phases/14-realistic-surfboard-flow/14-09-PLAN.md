<objective>
Let a board remember where a shaper set each tip's thinning to start — and nothing else changes.

Each board's blank gains two optional numbers: where the nose's thinning starts and where the tail's does, in from
that tip. A board without them — every board saved so far, every preset, every new board — is on Automatic. The
values are read forgivingly: a broken one reads as Automatic and never stops a board opening. No database change is
needed (a saved board is one JSON value), the saved-board version stays 5, and the live site of go-live 1 would still
open a board saved later.

Purpose: D-24, D-06, R6, R8; the stored-start edges.
Output: two optional fields on `BoardBlank` and in the parser, and their tests.
</objective>

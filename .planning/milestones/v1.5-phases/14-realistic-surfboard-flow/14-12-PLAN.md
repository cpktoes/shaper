<objective>
Hand each tip's thinning start to every screen through the one side profile, and make sure a start set by hand
reaches every place a board is worked out.

After this plan the side profile — the single description of the board seen from the side that ROCKER, the
DATASHEET, RAILS, VOLUME, the rack cards and the order form all read — carries, for each tip, where its thinning
starts, whether that is Automatic or set by hand, what Automatic would pick, the slider's reach, and the too-close
flag. A start set by hand gives the same numbers whichever way the board is worked out. The before-and-after
comparison learns the tips: what was live after go-live 1 against what will be live after go-live 2. Nothing on
screen changes yet.

Purpose: R6, R8, R9; D-02, D-12, D-18, D-24; Pitfall 5.
Output: `BlankSideView.tips`, the starts plumbed through the profile and `summarizeDesignWith`, `RULES_BEFORE_TIPS`,
and the cross-path test.
</objective>

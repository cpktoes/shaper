<objective>
Switch the board itself over: saved boards learn version 4, the design store learns about blanks, and
the ROCKER screen's hand-set rocker becomes five typed stations.

This is the plan where the stored rocker changes shape, so it changes everything that reads it in one
go. A saved board now carries its blank's own station rows, the placement and the two 12" fine-tunes
(D-01). Boards saved before this phase reopen exactly as they looked — the old curve is read as five
stations (D-02, D-14). The store builds one side profile — from the blank when one is picked, from the
five stations when not — and RAILS, VOLUME, the drawing, the DATASHEET and the Summary's rocker box all
read it. It gains the moves the new screen needs: pick a blank, slide it, fine-tune, reset, remove.

On the ROCKER screen, the Angle, Smoothness and Flatness sliders go; four plain sliders set the nose
tip, nose 12", tail 12" and tail tip rocker instead, and the DATASHEET's rocker row can be typed again.
The DATASHEET also learns to show the blank's numbers beside the board's, ready for when the list
arrives (11-11). The dev-only "Copy preset values" button learns to print a blank line.

Purpose: R1, R4, R5, R6 (store half), R14; decisions D-01, D-02, D-11, D-12, D-14, D-16.
Output: snapshot v4, the store's blank and side profile, the fallback rocker controls, both DATASHEET
states, the capture printer, and the phone test that named the retired sliders.
</objective>

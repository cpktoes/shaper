<objective>
Put the five fit and tip defaults where a shaper already changes Imperial/Metric: the gear menu.

A new BLANKS group appears under Theme with one row, "Fit & Tip Defaults". It opens a small dialog with
two groups — WHICH BLANKS FIT (Extra Length 2", Extra Center Thickness 3/8", Width Margin 1") and NEW
BOARDS START WITH (Nose Tip 5/16", Tail Tip 1/4") — each a typed field that takes effect the moment it
is committed, a Restore Defaults link, and Done. The numbers follow the shaper to any device when
signed in and are remembered by the browser when not, exactly as the units choice is, and they are
right on the very first paint because the server resolves them.

The design store and the ROCKER screen start reading these in plans 11-10 and 11-11 (new boards'
tips; which blanks fit). This plan only makes them settable and available.

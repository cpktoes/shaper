<objective>
Build the ROCKER sidebar the brief describes, top to bottom: set the centre thickness, pick a real
blank, slide the board along it, read the numbers, set the tips and fine-tune.

- **CENTER THICKNESS** first — a typed field and a slider writing the board's one centre thickness.
- **BLANK** — a list of every blank long enough and thick enough (from the shaper's own settings),
  shortest first, the ones that fit on top and the ones that don't greyed with the reason ("1/8" too thin
  12" from the nose"), with a search box. Picking one lands the slider where it fits nearest the centre.
  Once picked, a card shows it with Change Blank and Remove This Blank; if the board changes so it no longer
  fits, a flag says why and offers the closest blank that does — it never clears the pick.
- **BOARD ON BLANK** — the placement slider, nose to the left, and a small table of the rocker and the
  foam to come off at the five stations, changing on every move with no network request.
- **THICKNESS** — the tips, and the two 12" stations shown as "from the blank" plus the shaper's tweak.

The catalogue streams in from the server once per visit; the drawing and the controls never wait for it,
and if it fails to load the page says so while a picked blank keeps working from the board's own copy.

Purpose: R1–R6, R12, R14, R15 on screen; D-04, D-06, D-07, D-08, D-11, D-12.
Output: the page's streamed catalogue, the picker, the flag, the placement and readouts, the rebuilt
sidebar, ledger and allowlist entries, and the first browser spec of the finished screen.
</objective>

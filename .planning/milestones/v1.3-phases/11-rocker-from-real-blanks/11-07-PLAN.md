<objective>
Change what the ROCKER drawing shows and how: the board inside its blank, the foam to come off shaded,
and nothing on the drawing to drag.

The drawing stops building its own curve. It is handed one side profile (11-04) and draws it — rocker
below, deck above, the numbers on the rails as today. When the ROCKER editor also hands it a blank, it
draws that blank's side silhouette faintly behind the board, fits the frame to the whole blank, and the
shaded band between the blank's line and the board's outline is exactly the foam that comes off. The
Summary order form's small rocker box keeps drawing the board alone, as it does now.

With the Bezier gone as a live rocker (D-14), the tip handles, construction lines, drag state machine
and touch drag readout card have nothing left to shape, so they retire — along with the drag solver
file, and the old spline file that pchip replaced. Those are the phase's only file deletions, and they
all happen in one task here. The toolbar's construction toggle becomes "Show measuring points": the
five stations as plain dots, plus every station the catalogue measured when a blank is shown.

Until plan 11-09 gives the store its own side profile, the editor and the order form build the profile
from the saved curve with the same permanent conversion old boards will use on reopening
(`bezierToFiveStations`), so the screen keeps working in between.

Purpose: D-14 (retirements), D-15 (the drawing), R4 (numbers on the rails), R15 (density only).
Output: the rebuilt viewer and frame, two palette weights, rewritten viewer and e2e tests, four files deleted.
</objective>

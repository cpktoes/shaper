<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored snapshot → rendered card line | A saved board's snapshot is shaper-supplied JSON that has already been validated by `parseSnapshot`; its numbers reach the screen through this line. |
| built-in presets → rendered card line | `BOARD_PRESETS` is compiled-in data, not user input. |

No new trust boundary is introduced by this plan: it changes where a string is composed, not where
any value comes from.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-12 | Information disclosure | `CardMetadataLine` rendering a saved board's numbers | low | accept | The line shows only the board's own dimensions, on a page that already only lists that shaper's own boards (`listModels` is ownership-scoped). No new data is exposed. |
| T-05-13 | Tampering | a corrupt or hostile snapshot reaching `summarizeDesign` | low | mitigate | Unchanged from Phase 2: `app/page.tsx` validates every row through `parseSnapshot` and drops an unparsable one before it reaches a card. This plan adds no new path from stored data to the screen. |
| T-05-14 | Spoofing | rendered numbers misrepresenting what a preset click produces | medium | mitigate | `presetSummary` composes exactly the state `applyPreset` writes, and a source-contract test (added in 05-01) fails if `DEFAULT_DESIGN_STATE`'s volume or foil-link default changes without it. A card that quotes numbers a shaper will not get is the failure that matters here — these are numbers someone may cut foam to. |
| T-05-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package and adds no import outside the repo. No package manager runs. |
</threat_model>

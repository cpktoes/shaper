<objective>
Close the loop: make it mechanically impossible for a printed measurement to quietly stop following
the shaper's chosen system, and tell the truth in `CLAUDE.md` about where that now applies.

Phase 6 built this mechanism for the fifteen design-screen files and left a comment naming the
Summary order form as Phase 7's work. This plan grows the same ledger over the four print surfaces
and rewrites that comment, so the next person to add a printed number gets a failing test rather than
a shaper's phone call.

Purpose: a shaper who picks Metric gets every number on every page in Metric, today and after the
next feature lands.

Output: a closed conversion ledger over all four print surfaces; a durable assertion that no builder
call site is silently imperial; and a project doc that describes the boundary as it actually is.
</objective>

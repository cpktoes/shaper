<objective>
Make "the math is right" a machine-checked fact rather than a local one: every geometry suite runs
on GitHub for every push and pull request, and the three small derivation functions that stand
between the drawn outline and the litres figure get tested directly instead of only being brushed
past by one end-to-end test.

Purpose: the calculators are the product. A shaper cuts foam to these numbers, so "passes on my
machine" is not a standard. This plan turns the existing golden-fixture suites into a gate that
cannot be skipped, and closes the one real coverage hole RESEARCH.md found.

Output: `.github/workflows/ci.yml` (the repo's first CI workflow, verified to build without real
credentials) and an extended `lib/geometry/design.test.ts`.
</objective>

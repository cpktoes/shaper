  <action>
The reference lines on the outline drawing are deliberately faint on screen: `--outline-station-line`
is 36% of the muted ink token, and `--outline-widepoint-line` is 45% of the widepoint knot colour.
Low-alpha dotted and dashed lines are the first thing a printer loses, and the sheet prints at
roughly 0.69 zoom, so on paper these are the lines most at risk. That is exactly what the folded
todo's items 4 and 5 flag.

Raise them for paper only, inside the `@media print` block of `app/design/summary/order-form.css`
rather than in `app/globals.css`. Route-scoping is deliberate: the tiled 1:1 template PDF does not
read CSS at all, the Template editor screen is not printed, and the only surface that needs stronger
lines on paper is this order form. Override `--outline-station-line` and `--outline-widepoint-line`
with higher mix percentages against the same base tokens they already use — keep the `color-mix`
form and the same base tokens, so the four themes and the print palette forcing all still apply and
no literal colour value enters the stylesheet (the 260825-rqm lesson: a hardcoded colour in a
route-scoped stylesheet is a bug waiting to be found by a dark theme). Leave the dash patterns alone;
the widepoint dash pattern is what distinguishes it from the station lines and changing it would
break that distinction.

Match the print block's existing specificity discipline. The globals print block deliberately uses a
tripled `:root` selector so it outranks an explicitly chosen theme class; an override placed here has
to win against the same theme classes, so scope it to the order-form page element the file already
targets rather than to a bare selector that any theme class would beat. Note in a comment which
selector you chose and why, in the file's existing voice.

Change nothing about pagination, the page box, the margin or the font scale — all of that was
settled by 260822-nbz, 260823-pw7 and 260826-lg8 and is not what this task is fixing. Change nothing
that affects the screen: the screen values stay exactly as they are, which the verification below
checks.

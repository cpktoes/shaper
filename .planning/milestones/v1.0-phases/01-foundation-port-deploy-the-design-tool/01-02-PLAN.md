accident.

approved UI Design Contract: preset cards with real outline thumbnails (D-08), a Continue Current
Board card, a replace-board confirm dialog (D-07), and the wordmark-links-home nav change (D-06).

can actually read and trust.
Output: the setup screen as specified — 4 preset cards, conditional continue card, confirm dialog.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-04 | Tampering (XSS) | board name rendered in `components/setup/continue-board-card.tsx` | medium | mitigate | The board name is the first free-text field to reach a new surface. Render it as plain JSX children only — React escapes it. No raw-HTML injection prop and no string-built markup anywhere under `components/setup/`; enforced by the grep in Task 1's `<verify>`. Truncation is CSS-only, so no string manipulation can produce a malformed fragment. |

Review the generated file before committing; reject it if it reaches for the network, `eval`, or an undeclared package. |

## Shared Patterns

### Units boundary (mm internal, inches at the edge)
**Source:** `lib/geometry/units.ts:1-11` (doc comment) + `inchesToMm`/`mmToInches`/`degrees` functions (`lib/geometry/units.ts:22-30`)
**Apply to:** `lib/geometry/presets.ts` (author all values via `inchesToMm`/`degrees`), any new setup-screen numeric display (route through `mmToInches`/`formatInchesFraction`).

### Client-state action pattern (no effects that write state)
**Source:** `components/design/design-store.tsx:9-13` doc comment + `updateOutline`/`updateFins`/`setBoardName` actions (`:126-143`)
**Apply to:** `applyPreset` (new store action), `setup-screen.tsx`'s click handlers, `replace-board-dialog.tsx`'s confirm handler — every state write is a single `setState` call inside an event handler.

### Numeric input clamping before it enters store state
**Source:** `components/outline/outline-controls.tsx` — `clampFinite(v, min, max)` wraps every slider's `onChange`, e.g. `onValueChange={(v) => onChange({ widePointOffset: inchesToMm(clampFinite(v, -12, 12)) })}`
**Apply to:** Any new numeric input this phase adds to the setup screen (none currently planned per D-04, but applies if scope grows) — never write an unclamped value to `useDesign()`.

### shadcn/base-ui primitive construction
**Source:** `components/ui/button.tsx:1`, `components/ui/select.tsx:4`, `components/ui/card.tsx` — all import from `@base-ui/react/*` or are plain styled `<div>`s using `cn()` from `@/lib/utils`
**Apply to:** `components/ui/alert-dialog.tsx` (generated via `npx shadcn add alert-dialog`, not hand-written) and its consumer `replace-board-dialog.tsx`.

### No `dangerouslySetInnerHTML` / no `document.write`/`window.open`
**Source:** `components/outline/outline-viewer.tsx:9-11` doc comment (threat T-QO-01)
**Apply to:** Any component rendering preset `descriptor` copy or `boardName` — always plain JSX children, React's default escaping is sufficient.

### `LayoutProps<'/route'>` typed layout helper
**Source:** `app/design/layout.tsx:9` (`LayoutProps<"/design">`), current `app/layout.tsx:20` (`LayoutProps<"/">`)
**Apply to:** Keep using this exact typed-helper convention when editing `app/layout.tsx` and `app/design/layout.tsx` — do not revert to untyped children props (Next.js 16 convention, per RESEARCH.md).

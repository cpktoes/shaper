# Milestone v1.3 Requirements: Rocker from Real Blanks

**Status:** Locked 2026-09-25 from the founder's written brief as the phase's spec ([11-SPEC.md](v1.3-phases/11-rocker-from-real-blanks/11-SPEC.md)). No REQUIREMENTS.md was written for this one-phase milestone; the spec's sixteen numbered requirements are the record, and [11-VERIFICATION.md](v1.3-phases/11-rocker-from-real-blanks/11-VERIFICATION.md) traces every one of them to code and passing tests.
**Phase:** 11 (continuing from v1.2, which ended at Phase 10)
**Decisions:** D-01–D-20 in [11-CONTEXT.md](v1.3-phases/11-rocker-from-real-blanks/11-CONTEXT.md)

**Goal:** A shaper sets a target centre thickness, picks a real blank that fits, slides the board along it, and the board's rocker, thickness and foil are read off where it sits in that foam — the four rocker numbers and the foam to remove shown live, every blank that won't fit shown with why, and a foil that matches the shaper's centre and tip thicknesses; the four named geometry tests land before any UI.

## Notes

- **Accepted deviation (WR-05):** a saved board shorter than about 24 inches cannot be summarised by the geometry at all (its centre falls before the tail 12" station), so such a board is rejected and the rack drops only that card, instead of reopening hand-set. No board a shaper could have created in the app is that short; boards at 45" and 150" reopen hand-set as intended.
- **Policy, not code (CR-01):** the code review found that Drizzle names every column on insert, so an additive migration must reach production BEFORE the deploy. CLAUDE.md's Database rule was amended and the production step reordered; it ran in that order at the close.
- **Human checks:** the seven UAT items (the whole flow on a desktop, the drawing in four themes, defaults following the account across devices, real iPhone and Android touch, the presets' provisional blank picks, a pre-existing saved board, the two re-recorded reference screenshots) all passed with the founder on 2026-09-26.
- **Follow-ups filed, not gaps:** manufacturer tick-boxes for the blank list; a smoother-looking drawn curve without changing the PCHIP numbers; the foil-from-real-shaping model (deck skin, parallel bottom, pin-deck tip thinning).

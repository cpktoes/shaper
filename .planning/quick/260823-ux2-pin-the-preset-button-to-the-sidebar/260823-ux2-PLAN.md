# Quick Task 260823-ux2 — pin the preset button

The dev-only `Copy preset values` button is the last static child of a scrolling `<aside>`. That was
never a pinned footer — it only looked like one.

## Measured, all three editors at a 1400px-tall viewport

| Page | aside overflow | button reachable without scrolling |
|---|---|---|
| Outline | 0px | yes |
| Rails | 0px | yes |
| **Fins** | **44px** | **no** — pushed 4px past the aside's bottom edge |

The markup is byte-identical across the three. Outline and rails only appear pinned because their
controls happen to fit; the fins controls are longer, so the button falls out of view and you meet it
mid-scroll immediately under the fin model buttons — which is what the user saw. On a laptop-height
window the overflow is several hundred pixels and all three would behave like fins.

## Fix

Restructure each aside into a flex column: a `min-h-0 flex-1 overflow-y-auto` region holding the
controls (the existing `p-10` moves onto it, so the padding scrolls with the content), and a
`flex-none` footer holding the button, separated by a top border.

Applied to all three so the behaviour is structural rather than a coincidence of content length.

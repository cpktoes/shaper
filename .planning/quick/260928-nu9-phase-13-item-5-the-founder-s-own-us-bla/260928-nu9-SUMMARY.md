# Phase 13 Item 5: The Founder's Own US Blanks Picks Summary

Each of the four preset cards — Shortboard, Fish, Mid-length, Longboard — now opens in a real US
Blanks blank the founder chose, captured through the same ROCKER-screen capture loop that already
tunes every other preset field. Nothing is left on a provisional, rule-picked blank, and a new
guard test fails if one ever slips back onto one.

## Performance

- **Duration:** ~25 min
- **Tasks:** 2
- **Files modified:** 6

## Accomplishments

- All four presets carry a captured `blank: { … }` line in `lib/geometry/presets.ts`, produced by
  calling `buildRockerPresetSource` (never typed by hand), each centred at placement 0:
  - Shortboard → US Blanks `6'3"EA`
  - Fish → US Blanks `5'10"RP`
  - Mid-length → US Blanks `7'4"SP`
  - Longboard → US Blanks `9'3"Y` (the same blank as its old provisional pick — now the founder's own)
- `lib/blanks/preset-blanks.generated.json` was regenerated by `scripts/generate-preset-blanks.ts`
  (never hand-edited): all four picks marked `"provisional": false`, holding exactly the four US
  Blanks blanks' rows. A second run of the generator produced byte-identical output.
- The one test the change broke — blank-fit.test.ts's D-16 Pin-deck/Bottom tip-style test, which
  used to read the Shortboard's pick out of the generated JSON — now names its blank directly:
  `findBlank("Marko Foam", "6'4\" TP")`, the Shortboard's own former pick. Its assertions are
  byte-for-byte unchanged.
- A new guard test, `lib/blanks/preset-blanks.test.ts` "every preset carries the founder's captured
  blank, so none is left provisional (Phase 13 item 5)", fails if any preset's `.blank` is undefined
  or if any pick in the generated module is still marked provisional.
- Test titles and one doc comment that used to call the four picks "provisional" were reworded to
  describe the current state (captured, not stale) without touching any test's body/assertions.

## Which tests changed, and why

- **blank-fit.test.ts** — the D-16 test ("makes a tip thicker than the parallel foil there as thick
  as set... (D-16)") is the one test this change genuinely broke: it used to read the Shortboard's
  *current* pick out of the generated JSON to get a real blank whose tail runs thinner than the
  Shortboard's 15/16" tail tip. The new US Blanks `6'3"EA` blank's tail is thick enough that
  `pin.tipThinningAt(0) < 0` etc. no longer hold, so the test would silently stop proving D-16 on
  the new blank. It now names the old Marko Foam `6'4" TP` blank directly (still a real catalogue
  blank, just no longer any preset's pick) via the file's existing `findBlank` helper, at `mm(0)`.
  Every assertion in the test body is byte-for-byte unchanged; only the blank lookup and its comment
  changed. The unused `presetBlanks` generated-JSON import was removed (its only remaining use was
  the deleted `pick` lookup) — leaving it would have failed `--max-warnings 0`.
- **preset-blanks.test.ts** — one new test added (guard, described above); three existing test
  titles reworded to stop describing the current state as "provisional" (their bodies are
  unchanged): the `it.each` at the top of the first describe block, the "has not gone stale" test,
  and the "wins over the provisional pick" test (retitled "decides the blank a preset opens in" —
  its body still swaps the Shortboard's captured pick into the Fish, a valid proof now that every
  preset has a captured line).
- **e2e/new-board.spec.ts** — comment-only change (dropped "(provisional)"); no test code touched,
  per the plan (the orchestrator runs the browser suites).

## Decisions Made

- The founder's four US Blanks picks (2026-09-28, Phase 13 item 5) were captured by calling
  `buildRockerPresetSource` directly in a scratch script rather than through the live browser — the
  function is pure and produces byte-identical output to the "Copy preset values" button, so no
  browser session was needed for this quick task.
- The D-16 test's fix names the Shortboard's *old* blank (Marko Foam `6'4" TP`) directly, rather
  than trying to find a different US Blanks blank whose tail happens to be thin enough — the old
  blank is still a real, unmodified catalogue entry, and the plan's own reasoning (a real blank
  whose parallel foil at the tail runs thinner than the setting) is best served by the blank that
  was already known to prove it.

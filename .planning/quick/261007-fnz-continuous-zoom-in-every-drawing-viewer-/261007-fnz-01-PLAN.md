<objective>
Continuous zoom for the drawings, built once as a shared piece and shown first on ROCKER. Over the side view, the
mouse wheel and a trackpad pinch zoom from 1x to 10x in half steps toward the point under the pointer; on a phone two
fingers pinch and pan; above 1x a mouse drag pans, never past the edge of the drawing; a small control under the
toolbar shows the level ("2.5x") with zoom-out, zoom-in and reset; a double-click or double-tap goes back to 1x. Lines,
dots and words keep their screen size at every zoom, and a grid appears that gets finer as the shaper zooms in.
Nothing is saved.

same component to the others without re-implementing anything per viewer." This plan designs the shared API once, so
plan 02 only wires TEMPLATE, RAILS, FINS and the TOP VIEW tab.

in `callout-primitives.tsx` made zoom-aware, ROCKER wired, `e2e/viewer-zoom.spec.ts`, ROCKER's desktop baseline
re-recorded, the 1x before/after proof shots and the founder's pictures (ROCKER at 1x and at about 6x on the nose with
the grid, Imperial and Metric). No SUMMARY in this plan: plan 02 writes it for both.

- **P9 — Rotating the board resets to 1x** (the provider is keyed on orientation; a turned frame has a different

<interfaces>
The API this plan creates and plan 02 only wires. Names are fixed; internals are the executor's.

`components/viewer/zoom-math.ts` (pure; no React, no DOM; `mmToInches` from `lib/geometry/units.ts` is its only
import from the app):
- Constants: `MIN_ZOOM = 1`, `ZOOM_STEP = 0.5`, `DEFAULT_MAX_ZOOM = 10`, `GRID_MIN_GAP_PX = 20`,
  `WHEEL_BURST_GAP_MS = 150`, `WHEEL_STEP_PX = 100`, `PINCH_WHEEL_RATE = 0.01`, `DOUBLE_TAP_MS = 300`,
  `DOUBLE_TAP_SLOP_PX = 30`.
- `interface ViewRect { x: number; y: number; width: number; height: number }`,
  `interface ClientSize { width: number; height: number }`,
  `interface ZoomState { zoom: number; center: { x: number; y: number } | null }` (null centre = the base's centre).
- `snapZoom(z, maxZoom)`, `stepZoom(z, steps, maxZoom)`, `formatZoomLevel(z)` ("1x", "1.5x", "10x").
- `parseViewBox(s): ViewRect | null`, `formatViewBox(r): string`.
- `baseFit(base, client)`: min(client.width / base.width, client.height / base.height), 0 if unmeasured.
- `zoomedView(base, client, state): ViewRect` — at zoom 1 returns `base` itself; above 1 the client-aspect rectangle of
  size client / (fit × zoom) around the centre, each axis clamped inside the base (or centred on it when wider).
- `clientToUser(viewBox, client, px, py)` — the `xMidYMid meet` mapping, valid for the base (letterboxed) and a zoomed
  view alike.
- `zoomAt(base, client, state, newZoom, px, py): ZoomState` — the user point under (px, py) stays at (px, py) unless the
  clamp moves the view; `newZoom` 1 returns `{ zoom: 1, center: null }`.
- `panBy(base, client, state, dxPx, dyPx): ZoomState` (clamped; a no-op at 1x).
- `pinchState(base, client, start: ZoomState, startMid, startDist, mid, dist, maxZoom): ZoomState`.
- `wheelStep(acc: { sum: number; lastMs: number }, deltaPx, nowMs): { acc; steps }` (P6) and
  `normaliseWheelDelta(deltaY, deltaMode, pageHeightPx)` (lines × 16, pages × page height).
- `zoomUnitTransform(x, y, zoomUnit): string | undefined` — undefined at exactly 1, otherwise
  `translate(x y) scale(u) translate(-x -y)` so a symbol keeps its screen size about its own anchor.
- `scaleDash(dash: string | undefined, zoomUnit)` — the same string (or undefined) at exactly 1.

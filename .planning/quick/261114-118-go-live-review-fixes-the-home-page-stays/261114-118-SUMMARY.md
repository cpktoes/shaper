## 4. IN-01 — header figures bounded

`headerNumber` now returns null when the figure is not finite or `abs > 10,000` (the knots' `BRD_READ_MAX_CM`). That is exactly how a non-finite header figure was already treated: an absent length means the file is unreadable; an absent width or thickness falls back to the outline's own. Test: `p01 : 1e308` and `10001` read as unreadable; `p03` / `p04` of `1e308` read as null with the board still reading; `p04 : 10000` (the limit) still counts; an ordinary file unchanged.

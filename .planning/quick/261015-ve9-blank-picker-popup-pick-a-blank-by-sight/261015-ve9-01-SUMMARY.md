# Phase quick-261015-ve9 Plan 01: Pick a blank from a popup of drawn blanks — Summary

On ROCKER, the BLANK section is now one button. It opens a PICK A BLANK popup where every blank long
enough for the board is a catalogue card. Each card shows the blank from above over its rocker from
the side, drawn with the main view's own curves at true proportion, with the shaper's board dashed on
it and the catalogue's printed station table underneath. A blank too thin at the center is no longer
hidden: it shows greyed, with the fit flag's own sentence. Picking a card closes the popup and puts the
blank on the board.

## What a shaper sees

- **With no blank:** the BLANK button reads PICK A BLANK, then a line like "196 blanks long enough
  for this board, 194 fit", then BROWSE BLANKS ›.
- **With a blank:** the button shows a small drawing of that blank, its name and litres, its
  maker · length · center line, and CHANGE BLANK ›. The fit flag, Remove This Blank with its
  sentence, the makers note and the catalog note are all where they were.
- **The popup:**
  - On a computer it fills the window 32 px in from each edge and is never wider than 1180 px.
    On an upright phone, and on a phone held sideways, it fills the whole screen.
  - The header reads "PICK A BLANK  for your 6'0" × 19" × 2 1/2" board · 196 of 196 blanks · 194 fit".
  - Below the header: a search box, the list's intro line, then FITS THIS BOARD · n and WON'T FIT
    THIS BOARD · n, shortest first.
  - The ✕, Esc or a click outside closes it and leaves the board exactly as it was.
- **A card:**
  - Header: the name on the left; on the right the blank's measured length · litres, e.g. `6'2 3/4" · 55.1 L`.
  - Then the maker, then the drawing (outline from above, stringer, centre mark, width dots, your
    board dashed, the rocker from the side resting on a faint line), then the station table: Nose,
    N 12", Center, T 12", Tail × Width, Thick, Rocker, with "—" where the catalogue prints nothing.
  - There is no text line under the drawing (D-09).
  - A greyed card mutes its name and gives the reason in warning ink, never faded.
  - The board's own blank has an accent border and ON YOUR BOARD NOW.
- **A locked board:** the popup still opens and searches, but no card can be picked.
- **Metric:** lengths and widths read in centimetres (`188.9 cm`), thicknesses and rocker in whole
  millimetres. The table rows read Width (cm), Thick (mm) and Rocker (mm), and the columns N 30.5 cm
  and T 30.5 cm.

## Deviations from Plan

### Auto-fixed issues

1. **[Rule 3 – blocking] Two test ledgers named the old file.** `lib/units-isolation.test.ts` requires
   every screen file that imports `lib/geometry/units` to be listed. It now lists
   `blank-picker-dialog.tsx` and `blank-card.tsx`. It also accepts `blank-card-text.ts` as reading
   through the display boundary, with a new test proving that file imports `measure-display` and
   calls no banned formatter. `components/ui/input.css.test.ts`'s list of the five places that use
   the shared Input now names `blank-picker-dialog.tsx` (where the search box moved) instead of
   `blank-picker.tsx`. Both files are outside `files_modified`. They are ledger updates only. (Commit 8819ad75.)
2. **[Rule 1 – test] `viewer-zoom.spec.ts` dragged a slider it could not reach.** The new BLANK button
   stands a little taller than the old picked card. On an 800-dot window that leaves the Placement
   slider just under the sidebar's fold, behind the dev-only "Copy preset values" footer, so the
   mouse drag landed on the footer. The test now scrolls the slider into view first, as
   `touch-drag.spec.ts` already does. (Commit e5b6b92a.)
3. **[Rule 2 – focus] Change Fit Rules waits for the popup to finish closing.** If the popup closes
   and Settings opens in the same moment, the popup's "give focus back to the BLANK button" can
   steal focus from Settings' WHICH BLANKS FIT heading. Instead, the popup closes with focus return
   turned off, and opens App Default Settings from Base UI's `onOpenChangeComplete`. Two modal
   dialogs are never open at once, and the app-settings focus test stays green.
4. **Summary specs keep their own `pickFirstFittingBlank`.** `summary-blank.spec.ts` needs the pick to
   return `vendor name` read off the card's accessible name, not just the name. It keeps a small
   local version built on the shared helper's pieces (`openBlankPicker`, `firstFittingCard`,
   `cardButton`).
5. **Task 3 became three commits.** The plan allowed two (the screen, then the specs). The third,
   6e8e5858, writes `vectorEffect="non-scaling-stroke"` out on each SVG element instead of spreading
   it from a shared object. It renders the same, but the plan's acceptance grep looks for the literal
   attribute.
6. **TDD order.** In Task 1 the `listBlanks` rewrite was written just before its tests, not after.
   Every test was then run against it (the R2, Pitfall 6, D-10, D-06 and empty-list tests were
   rewritten in their new form, none deleted). Each task is one commit, as the plan's
   executor_environment says, so there are no separate RED/GREEN commits.

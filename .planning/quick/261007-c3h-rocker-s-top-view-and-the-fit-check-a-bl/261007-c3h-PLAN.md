<objective>
A foam blank whose catalogue prints its nose 0 wide gets a round nose on ROCKER, the way the foam actually looks,
instead of a point. Inside the last printed width station the blank's full width becomes the parabola the founder
picked in sketch 012 (variant C): W(d) = A·√d + B·d, d the distance in from the tip, fixed by the printed width at
that station and today's own slope there. The outline leaves the tip straight across the stringer, meets the station at
its printed number with no kink, and everything from that station back is today's curve exactly. The fit check reads
the same curve, so a board refused as too wide right at the nose can come to fit; nothing that fits today is refused.

nothing is stored: the two numbers that shape the nose come from the printed widths alone.

tests, a golden fixture generated by running the sketch's own code, and catalogue-wide proofs; the top view sampling

<decisions>
Locked by the founder (sketch 012, 2026-10-07) and the orchestrator. Do not reopen them. Each task cites the ones it
implements.

- **D1 — The rule (sketch 012 C).** Inside the last printed width station before a tip printed 0 wide, the blank's
  FULL width is W(d) = A·√d + B·d, d the distance in from the tip in millimetres. With D = the distance from that
  station to the tip, W_k = the station's printed width, and M_k = today's curve's slope there taken toward the tip
  and positive when the width falls toward the tip (nose: M_k = −slopeAt(x_k) of the square-root fall curve; tail:
  M_k = +slopeAt(x_k)): A = 2·(W_k − D·M_k)/√D and B = 2·M_k − W_k/D. It meets the station at W_k and at today's
  slope and leaves the tip across the stringer. From that station back to the far tip the curve is today's square-root
  fall curve EXACTLY (bit-identical), and every printed station reads its printed value exactly.
- **D2 — Guard.** Round a tip only when it prints 0, the last printed station before it prints more than 0, and
  A > 0. Otherwise the curve is today's, unchanged. (A > 0 on all 43 catalogue blanks; keep the guard anyway.)
- **D3 — Width only.** Never the blank's thickness or rocker, never a hand-set board's foil (`fallbackProfileWith`
  also uses the "fall" rule), never `prepareRootCurve` itself. A pure wrapper over a prepared curve
  (`lib/geometry/round-tip.ts`: takes a `PreparedPchip`, returns a `PreparedPchip` with the same xs/ys), applied in
  `prepareBlankWith` to the width curve under the "root" rule only. The "pchip" rule, kept by name for old boards,
  stays exactly as it is.
- **D4 — Both tips.** A 0-wide tail with a wider station before it rounds the same way. No catalogue blank prints
  one, so prove the tail with a synthetic record in a test.
- **D5 — Slope.** `slopeAt` inside the rounded segment is the parabola's own derivative (signed for the curve's
  direction); past either end 0, as today. At the rounded tip itself: `slopeAt(x_tip)` and `slopes[tip index]` read
  −Infinity at a nose and +Infinity at a tail (nothing in the app reads a width slope — verified). Say why in the
  code comment and test it.
- **D6 — The drawing follows the curve closely.** `buildBlankTopView` adds samples inside the last printed segment
  at BOTH tips, spaced evenly in √(distance from the tip) — a drawing parameter, always on, harmless on a square or
  pointed tip — enough that the drawn line never strays more than about 0.5 mm from the curve on the 7'4"SP and the
  9'4"B; test that bound. `TOP_VIEW_SAMPLES` in `components/rocker/rocker-top-view.tsx` stays as it is.
- **D7 — Fit consequence accepted.** A rounder nose adds foam inside the last printed station, so a board refused as
  too wide there can come to fit; no board may go from fitting to refused. Prove both on the whole catalogue: inside
  the rounded segment the new width is never below today's (the fall rule without the wrapper), and the stress set
  (`buildStressSet`) refuses no board that fits today. Count the freed boards with `annotate`, never as a typed
  number.
- **D8 — Golden, per Rule 1.** Copy the sketch's `curves.js` into `reference/sketches/012-round-nose-curves.js`
  with a header saying where it came from. A generator under `scripts/` runs its own `variantC` /
  `parabolaCoefficients` over the 43 affected catalogue blanks and writes
  `lib/geometry/__fixtures__/round-nose-golden.json`. A test reads the app's `prepareBlank(record).width.sample` at
  those positions and matches to 1e-6 mm. Never hand-type an expected number.
- **D9 — Nothing else changes.** No UI text, no control, no stored data, no database change, no change to the
  DATASHEET or the order form, and no change to the presets' recorded figures (litres come from the board, not the
  blank). Saved boards simply redraw. The side view is untouched.
- **D10 — Pictures for the founder.** Before AND after pictures of ROCKER's top view with the Mid-length preset
  (7'4"SP) and the Longboard preset (9'4"B) at 1280×800 (the mini display), plus the TOP VIEW tab on an iPhone 14,
  saved under the task folder's `pictures/`. The "before" pictures come FIRST, from the unchanged code, then the
  change, then the "after" pictures.

Planner's choices (Claude's discretion, each recorded so the founder can overrule):
- The wrapper also requires M_k ≥ 0. This is not a new rule. On a square-root fall curve the slope at the station
  before a 0-wide tip always points down toward the tip, so M_k ≥ 0 always holds there (proof in the file header).

- The before pictures get their own commit, made before any code changes, so the history shows the order D10 asks

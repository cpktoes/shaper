In shaper terms: the Deck Skin control on ROCKER and in Fit & Tip Defaults now runs from 0" to 1". 0 means the
planer takes nothing off the blank's deck, so the board's deck is the blank's own deck. When that's the case, every
line that mentions the skin says so in plain words instead of quoting a `0"` skin.

The founder decisions this plan implements continue item 4's numbering (4a used FD-1 to FD-4):
- **FD-5, the range.** The control offers 0" to 1" in 1/16" steps. Metric offers **0 to 25 mm**, decided by the
  existing rules rather than chosen here: `metricSliderRange` rounds each end inward to a whole millimetre, so
  25.4 mm becomes 25 mm (measured below). This is the same rule every Metric slider in the app follows. A 1" skin
  set in Imperial is stored as 25.4 mm and reads `25 mm` in Metric, with the thumb at the end and nothing written.
  The out-of-the-box skin stays 1/8" (`DEFAULT_BLANK_CUT.deckSkin`, untouched). "Default" in this task's title
  means the Fit & Tip Defaults dialog's Deck Skin box, which reads the same range constant.
- **FD-6, 0 means no deck skin.** What follows in code was confirmed by reading it, not assumed (blank-fit.ts):
  - The deck side of the fit check (`thinBy` uses `deckOffAt = deckSkin + …`) is 0 at every station under Pin
    deck with no Deck fine-tune, so it passes trivially.
  - The centre floor (`floorCheck`: target + deckSkin + planerMaxDepth) becomes target + one bottom pass.

    off reads sensibly, so the row is left unchanged.

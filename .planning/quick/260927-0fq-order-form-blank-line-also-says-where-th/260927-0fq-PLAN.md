<objective>
The founder's words: "on summary of blank, add center offset note with blank name."

In the app: page 2 of the printed order form (the Shaper Reference sheet) ends with a shaded
**Shaper Use Only** box. Since quick task 260926-wkh (merged today) its full-width **Blank** line
prints the blank picked on ROCKER as vendor then name (`US Blanks 6'2"A`), or an empty ruled line
when the board has no blank. This plan adds where the board's centre sits on that blank, which is the
Placement a shaper sets on ROCKER, so the shop can lay the board on the blank from the sheet alone:

- At the starting spot: `US Blanks 6'2"A — centered`
- Slid along the blank: `US Blanks 6'2"A — center 1/4" toward tail` (Metric: `— center 6 mm toward tail`)

The wording comes from `formatPlacement` in `lib/geometry/blank-reasons.ts`, the helper ROCKER's
own `Placement — ...` label uses. A placement is a mark (CLAUDE.md Rule 2): sixteenths of an inch
in Imperial, whole millimetres in Metric. The placement is the side profile's own, the same number
ROCKER's label reads, so the two screens can never disagree.

**Measured at plan time, correcting the brief.** The brief quoted "about 328 px of room" for the
field in print. That figure came from the previous plan's pre-layout estimate. Measured today on
main (7e142f7), in a desktop browser with the field on its own line:

| | Room for the value | Widest name | Widest placement note | Name + note |
|---|---|---|---|---|
| On screen | 737 px | 297 px (`Marko Foam 10'0" MK-SUP-STD`) | 295 px (`— center 44 13/16" toward nose`) | about 597 px, fits |
| In print | 603 px | 248 px | 246 px | about 499 px, fits |

The worst case anywhere is a 60" board (the shortest the app allows) on the 12'6" blank, which
can slide 45 1/4" either way. Trying all 162 names against all 3,747 wordings ROCKER's slider can
produce, in both systems, cut off **none**. So the design stands exactly as briefed, with no layout
change, and Task 2 turns that measurement into a permanent browser test.

Purpose: the shop's record of the job says which blank to use and where on it the board's centre
goes, in the same words ROCKER shows the shaper.
Output: the extended Blank line; three new or changed browser tests; a SUMMARY with a plain-English
note for the founder.

lib/geometry/blank-reasons.ts (read-only for this task; a sibling task owns nearby code):
- `formatPlacement(placement: Mm, system: UnitsSystem): string` returns `1/2" toward nose`,
  `1/4" toward tail`, `13 mm toward nose`, and exactly `centered` when the amount prints as zero
  in the chosen system. Placement is stored positive toward the nose.
- `placementSlider(placement: Mm, range: { min: Mm; max: Mm }, system: UnitsSystem): MeasureSliderView`
  gives `{ value, min, max, step, toMm(v) }` in the slider's own unit. Imperial step is 1/16"
  (0.0625); Metric step is 1 mm. Both ends sit on the grid, and zero is always a step.

lib/geometry/blank-fit.ts: `placementRange(blankLength: Mm, boardLength: Mm): { min: Mm; max: Mm }`
gives each end at (blank length minus board length) / 2 minus 1/2".
lib/geometry/board.ts: `BOARD_LENGTH_RANGE_IN = { min: 60, max: 120 }`, the OUTLINE length
control's bounds (the shortest board a shaper can set).
lib/geometry/units.ts: `inchesToMm`, `mm`, `type Mm`, `type UnitsSystem`.

components/design/design-store.tsx, from `useDesign()`:
- `blank: BoardBlank | null`. `blank.copy` is the board's own copy of the catalogue record
  (`vendor`, `name`, `lengthMm`, ...). The object also stores a raw requested placement, which can
  sit outside the blank's range after the board is lengthened. Do NOT print that one.
- `sideProfile.blank: BlankSideView | null`. Its `.placement` is "the placement actually used —
  the requested one clamped into range on read". It is built from the same blank in the same
  render, so it is non-null exactly when `blank` is.

clamped placement is 0 and formatPlacement also reads `centered`).

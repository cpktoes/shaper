Founder decisions, 2026-09-30, locked:

- **F-1 — Placement.** The phone's existing floating pair, extended to the desktop shell: ONE floating pair at the
  bottom-right of the window on all six design screens (TEMPLATE, ROCKER, RAILS, VOLUME, FINS, SUMMARY), never on the
  home screen, never inside the viewer cards. Same look on every device. Read as: the pair stays one element mounted
  once in `app/design/layout.tsx` and fixed to the window, never a button built into any viewer card's own toolbar or
  corner. On a computer the window's bottom-right corner is the drawing card's corner (the drawing column has only
  12 px of padding), so the pair floats above that corner, the same way it floats over the controls on a phone.
- **F-2 — Visibility.** It appears once there is something to undo or redo, with the arrow greyed (disabled) on the
  side that has nothing, exactly what the phone does today. Not always on. The existing early return (nothing at all
  while both `canUndo` and `canRedo` are false) stays exactly as it is.

  file name, the `PhoneUndoBar` export name and the `data-phone-undo-bar` attribute (three browser specs locate the

## Accomplishments

- The preset cards and the Continue Current Board card on the home page now draw a clean, thin khaki line around themselves when nothing is hovered — the same treatment the working panel already uses on every design screen (`/design/outline`, `/design/rails`, etc.).
- Combined with the thumbnail well's own faint inner line (added in the previous quick task, 260826-ist), the card now shows the same two nested lines from the founder's reference screenshot: an outer line saying "this is a card" and a fainter inner line saying "this is the picture inside it."
- The old resting ring — a faint grey halo that was there in the code but essentially invisible on screen in every theme — was removed. It would have sat one pixel outside the new line and made the edge look smudged, so taking it away was the right call, not an oversight.
- Nothing else changed: page colour, card colour, well colour, card size, spacing, and the grid are all exactly as before. Hovering a card or tabbing to it with the keyboard still lights the edge up in the accent colour exactly as it always has — that part of the code was untouched.

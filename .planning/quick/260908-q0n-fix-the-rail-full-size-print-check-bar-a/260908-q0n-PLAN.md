<objective>
Make the View Full Sized dialog's 2-inch check bar actually print, and put the rail's name on the
printed page.

Purpose: the shaper printed a full-sized rail on 2026-09-08 and reported two faults in plain words —
"The printed version does not include the 2 inch bar. It has the words, but no bar. We also need the
print to inform you which rail profile has printed." Both are real and both are one-line causes. The
bar is a plain div whose only ink is a background colour, and browsers throw background colours away
on paper unless the shaper ticks "Background graphics" in the print dialog, which is off by default
in Chrome and Safari — so the caption prints and the bar does not. The rail's name sits inside the
dialog header, which the print stylesheet hides along with the rest of the dialog's chrome, so the
one piece of text naming which rail is on the page never reaches the page. Phase 8's own print
measurement missed the first fault because a headless print probe passes `printBackground: true`,
which is the one setting a real shaper does not have on.

Neither fault is cosmetic. The check bar is the shaper's proof that what came out of the printer is
really 1:1 before they cut foam to it (D-14), and an unnamed sheet is indistinguishable from the two
other rails printed beside it.

Output: two changes in one component and its source-contract test file, one commit each. No change
to app/design/rails/actual-size.css, no new component, no new dependency, no number changed
anywhere, nothing under lib/geometry/ touched, and nothing different on screen.
</objective>

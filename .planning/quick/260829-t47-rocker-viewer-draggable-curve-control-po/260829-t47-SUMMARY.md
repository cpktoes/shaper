# Phase 260829-t47 Plan 01: Rocker viewer draggable curve control points Summary

Made the rocker screen's four curve-steering handles grabbable (matching the TEMPLATE screen),
retired dragging on the two tip points, and redrew the five station read-outs as bordered data
cards on a card surface now shared with the TEMPLATE screen.

## What changed, in plain English

**You can now grab the rocker curve's steering handles and reshape it, the same way you already
could on the TEMPLATE screen.** With "Show construction lines" on, four lines run from the curve
out to small round grab points. Drag the one at the very tip of the nose or tail line and the
curve bends with it — the Nose (or Tail) Angle and Smoothness sliders in the sidebar move right
along with your drag. Drag one of the two grab points near the middle of the board and it moves
the Nose Flatness or Tail Flatness slider instead — pushing that one up or down does nothing,
because the curve is flat through the center by construction, so only side-to-side motion means
anything there.

**The nose tip and tail tip themselves are no longer grabbable.** They now draw as small plain
dots, the same as the center point. A board's nose rocker and tail rocker are numbers a shaper
quotes and orders to ("a 4 1/2 inch nose") — not something to eyeball by dragging — so those two
numbers are still set exactly as before: from their own sliders in the sidebar, or typed directly
into the DATASHEET tab.

**The five numbers under the board — Tail Tip, Tail @ 12in, Center, Nose @ 12in, Nose Tip — now
sit in their own bordered cards**, instead of floating as loose text. Each card shows the station
name on top and its rocker and thickness numbers below. These cards use the exact same box style
(fill, border line, rounded corners) as the TEMPLATE screen's own input/output chips, so the two
screens now read as one drawing system. The Center card, which has no rocker number of its own
(the curve is zero there by definition), shows a dash instead of a blank row so all five cards
still line up evenly.

Nothing about the board's actual shape or dimensions changed — this only changes what you can
grab on the drawing and how the numbers under it are displayed.

## What was built

### Task 1 — `lib/geometry/rocker-drag.ts` / `rocker-drag.test.ts`
Rewrote the module from "two grabbable tip heights" to "four grabbable control points," inverting
`buildRocker`'s own forward formulas:
- `sideProfileDragPoints(geometry)` now enumerates the four Bezier handle termini straight off
  `geometry.handles`, in `buildRocker`'s own array order (tail tip's handle, centre-toward-tail,
  centre-toward-nose, nose tip's handle), each carrying its `anchor` (the knot it pivots around).
- `solveSideProfileDrag(geometry, target, dragged)` takes the live geometry first (matching
  `solveOutlineDrag`'s signature) and solves all four targets:
  - `tailTipHandle` / `noseTipHandle` — free two-degrees-of-freedom solve: direction gives the
    angle, length (re-evaluated against the cap at the *new* angle) gives the smoothness, inverted
    per `rocker.ts`'s own documented inversion (a short handle = high smoothness).
  - `tailFlatHandle` / `noseFlatHandle` — one-degree-of-freedom solve along the station axis only;
    the height component of the drag is discarded entirely, not approximated, because the centre's
    tangent has no height freedom.
  - No solve can produce `noseLift` or `tailLift`; `ROCKER_LIFT_RANGE_IN` is no longer imported.
- Every solved value is quantised against its own exported range
  (`ROCKER_ANGLE_RANGE_DEG`/`ROCKER_SMOOTHNESS_RANGE`/`ROCKER_FLATNESS_RANGE`), so a dragged shape
  can always be nudged afterwards from the matching slider.
- Test suite rewritten to cover all four targets: enumeration, identity (at default and an
  off-default spec), round trip, constrained-axis (height ignored), slider-representability,
  direction-of-effect (further drag = lower smoothness; zero-length = max smoothness), degenerate
  (non-finite) input, and exact patch-key sets. `npx vitest run` on this file plus `rocker.test.ts`
  and `outline-drag.test.ts`: 116 tests passed.

### Task 2 — `components/rocker/rocker-viewer.tsx`
Inverted which points on the drawing are grabbable:
- The three knots (tail tip, centre, nose tip) now draw as plain, ungrabbable dots.
- The four handle termini (`sideProfileDragPoints(geometry)`) are now the only round, three-part
  grab targets — same visual size, same three-part treatment (board-fill disc, accent ring,
  warning core), same transparent hit circles and cursor styling as before.
- `handleDragMove` now passes the live `geometry` as the solve's first argument, matching the new
  `solveSideProfileDrag` signature.
- File header rewritten to describe the new arrangement and where a tip's own rocker number is
  set instead (its slider, its typed DATASHEET cell).

### Task 3 — `components/viewer/callout-primitives.tsx` / `components/rocker/rocker-viewer.tsx`
- Extracted `CalloutChipFrame` (plus its `CALLOUT_CHIP_RADIUS` constant) as the one shared card
  surface: fill `var(--outline-page-bg)`, stroke `var(--border)`, rounded corners. `CalloutChip`
  now renders it in place of its own inline `<rect>`, with its own layout math and both callers
  (`CalloutChip` itself and the rocker viewer) unchanged in behavior — the TEMPLATE and FINS
  drawings render byte-identical to before.
- Rebuilt the rocker viewer's station rail as five cards. Added `STATION_CARD_HEIGHT` (50 user
  units) and `STATION_CARD_WIDTH` (derived from the rail's own 12in column pitch through
  `PX_PER_INCH`, minus an 8-unit gutter — works out to 74 units, sized in user units rather than
  pinned CSS pixels so it can never overlap a neighbour at any window size). `RAIL_LABEL_HEIGHT` is
  now `STATION_CARD_HEIGHT + 8`, still evaluating to 58 — `viewH` and every consumer's box aspect
  (including the Summary order form's rocker box) is numerically unchanged.
- Each card shows the station name on top (muted label color, 10-unit, existing letter-spacing),
  then the rocker value ("R …", ink color, 13-unit) and thickness value ("T …", ink color,
  13-unit). The Center card's rocker row reads "R —" in the muted label color since it has no
  rocker number of its own.

001 Callout grammar

Viewer callout system

Which grammar should dimension callouts use on the board viewers? Same board, same four measurements, four treatments. Geometry and fin positions are real, pulled from the running fin viewer; the tail silhouette is simplified for legibility at this size.

Today

Current

Free-floating labels, five line variants, two near-identical blues.

Measured defects

Five leader-line variants, three dash patterns at identical colour and weight. Labels #3A5F9E against lines #4472C4. No label backgrounds. Placement by per-label pixel arithmetic.

Why it reads messy

Six labels at six offsets — nothing shares an edge or a column, and values sit directly on the lines they annotate.

Option A

Dimension lines

Drafting convention: extension lines, end ticks, value in a break.

One ink

Every dimension shares a colour and weight; extension lines are the only light element.

Fixed offsets

Dimension lines stack at x=96 and x=124 rather than wherever they land.

Weakness

Offsets are chosen per drawing. Nothing stops the next label picking a new one.

Option B

Callout gutter

Values in fixed columns, short leaders to each anchor.

Overlap impossible

Two columns, fixed rhythm. Chips carry the page ground so they never collide with a line.

Weakness

Values sit away from the geometry they describe; reads more like a spec sheet than a drawing.

★ Selected

Hybrid — dimension lines on a fixed rail system

A's drafting grammar, C's alignment discipline. Outputs only: the tail-width input and its station label are gone.

The rail system

Four fixed offsets and nothing between them: two vertical rails left of the board, one horizontal below, one local to the fin cluster.

Shortest nearest the part

3 5/16" on the inner rail, 11" on the outer — standard drafting order, so leaders never cross.

Short spans break the rule

3/8" and 1 3/16" are too narrow to hold a value between their ticks, so the number goes outside.

Outputs only

Tail width and its station label were inputs already visible in the sidebar. Removed — see sketch 002.

Survives new labels

A new dimension joins a rail or defines one more. It can never land at an arbitrary offset, which is what produced today's scatter.

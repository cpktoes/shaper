# Sketch 008: Next-screen button

## Design Question
The founder's addition (2026-10-03): "add a button under the last control to go to the next page in
line, so no menu navigation is needed. It's almost wizard like." Each design screen ends with a way
on to the next one in the order — Template → Rocker → Rails → Volume → Fins → Summary — so the usual
walk through a board needs no menu at all, and ☰ is only for jumping around.

## How to View
open .planning/sketches/008-next-screen-button/index.html

## Variants
- **Today (for comparison)** — no step button; the tab bar is the only way between screens.
- **A: One Next button** — one full-width "Next: Rail Band Calculator →" under the last control;
  Summary says it's the last screen. Back is ☰ or the browser's own back.
- **B: Back + Next** — "← Rocker" and "Rails →" side by side; Template shows only Next, Summary only Back.
- **C: Steps + Next** — a six-step strip (tap any step to jump), "Step 3 of 6 — …", then Next.

## What to Look For
- Use "Scroll controls to the end" in the sketch tools and tap through all six screens.
- Whether the button reads as "next step" and never as Save or Submit.
- How it sits with the Undo/Redo pair floating in the corner (move a slider first): the controls
  end with room under the button so the pair never covers it.
- The first and last screens.

## Notes
Drawn on sketch 007's variant A frame (no tab bar, screens in ☰). The block fits any of 007's looks;
it would also work on today's layout if the tab bar stays.

## Outcome (2026-10-03)
**Winner: B — Back + Next.** Each design screen ends with "← previous" and "next →" side by side under
the last control; Template has only Next and Summary only Back. The "Together" tab shows it on sketch
007's winning frame (C, screen tiles in ☰).

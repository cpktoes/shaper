002 Inputs vs outputs

Inputs versus outputs

The Template page is mostly inputs — length, widepoint width, offset and tail block are all set with sliders. Only nose and tail width at 12" are read off the curve. How should the drawing tell the two apart? Real geometry from the running outline editor.

Option A

Outputs only

Apply the fins rule literally: show only what the app worked out.

Consistent

One rule on every page: the viewer shows computed values, the sidebar holds your settings.

Why it fails here

A template drawing with no length on it. The board's own dimensions are the subject of this screen, and two labels is not a template.

Option B

Inputs as reference dimensions

Drafting shorthand: given values in parentheses, muted.

Honest convention

Parentheses are the standard mark for a reference dimension — given, not derived.

Why it lost

The distinction is a typographic detail a non-technical shaper has to be taught. Everything still looks like one system.

★ Selected

Dual system — chips for inputs, dimension lines for outputs

Distinguish by system, not by punctuation or colour.

Dimension line = measured

Nose and tail width at 12" are read off the curve, on ticked dimension lines with the value in a break.

Chip = your setting

Length, widepoint width, offset and tail block sit in a left gutter under one header, visibly a different kind of thing.

The station line is the dimension line

No parallel rail added — the existing station line carries the ticks and the value.

Fins page differs deliberately

Outputs only there; its inputs are already in the sidebar and were judged clutter. The chip system exists for pages whose subject is the dimensions.

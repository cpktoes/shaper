# Milestone v1.1 — Imperial vs Metric: Audit Report

## What this milestone was

Every board Shaper stores has always been in millimetres. v1.1 gave the shaper a choice about how
those millimetres are *shown* — Imperial or Metric — and then made roughly 300 numbers across about
25 files honour that choice, without changing a single stored value. It landed in three passes a
shaper could try one at a time: the chooser itself (Phase 5), the five design screens (Phase 6),
and everything that comes out of a printer (Phase 7).

**Verdict: passed.** Every requirement is satisfied, every phase verified, and the seams between
the three phases hold. Nothing blocks archiving.

## Cross-phase integration — no breaks

This is what per-phase verification cannot see: whether the three phases actually agree with each
other. Checked at five seams, with the two load-bearing claims re-derived from source rather than
taken from the checker's report.

| Seam | Finding |
|---|---|
| **One source of truth** | `UnitsProvider` is mounted once at the root layout; the server resolves the preference in `lib/units-server.ts` so the page does not blink on reload. 25 components read it through `useUnits()`. The `shaper-units` cookie is touched in exactly one file, `lib/units-preference.ts`. No component creates a second provider or reads the preference behind the provider's back. |
| **The display boundary** | Both ledgers in `lib/units-isolation.test.ts` are fully closed — 15 design-screen files and 5 print-surface files — with completeness walks that fail if a *new* display file is added to either area and left unconverted. `components/summary/use-print-fit.ts` remains the single documented exception, and it scales paper, not boards. |
| **Chooser → screen → save → print** | Traced end to end. Verified directly: the units preference lives on its own `user_preferences` table (`lib/db/schema.ts`), never on `models`, and the only server action that touches units is `app/actions/units.ts` — the board-save path does not carry a system. There is therefore no such thing as "per-board units", exactly as CLAUDE.md's Rule 2 requires. |
| **One read, three printers** | `export-preview-dialog.tsx` calls `useUnits()` once (line 136) and threads `system` into all three of `downloadOverviewPdf`, `downloadStripPdf` and `downloadTemplatePdf`. No PDF surface can be handed a page of inches by omission. |
| **Round-tripping** | Switching systems is display-only: no screen writes a display-rounded value back into the store, so switching to Metric and back reproduces every value exactly. Phase 7 proved the printed half of this by rebuilding every Imperial PDF from the pre-milestone commit — all 68 pages byte-identical. |

## Tech debt carried into v1.2

None of this blocks the milestone; all four are recorded so they are not lost.

1. **A fragile bare formatter** (Phase 7, WR-02) — the template's Metric offset is produced by
   stripping ` cm` off a formatter's output with a regex. Correct today, but it breaks quietly if
   that formatter's suffix ever changes.
2. **The order form's rounding note** does not follow the chooser. It is a Phase 1 string living in
   the geometry layer, outside the display boundary, which is why nothing in v1.1 caught it.
3. **Nyquist validation was never reconciled** — phase 5 has no VALIDATION.md and phases 6 and 7
   are still `status: draft`. This is missing coverage, not a failure: a draft file's compliance
   flag carries no authority either way.
4. **No security pass for phases 5 and 7.** Phase 6's is verified with zero threats open. Phase 5
   is the one worth revisiting, since it added a database table and a server action.

## Bottom line

A shaper can pick Metric once, and from that moment the setup screen, all five design screens, the
Summary order form, the Overview Sheet, the Full Sized Template and the Paper Saver all read in
millimetres and centimetres — while the boards themselves are untouched, and a shaper who never
opens the chooser gets byte-for-byte the same app they had before. The test suite now fails if a
new screen or a new printed measurement quietly stops following that choice.

# The founder's review decisions, as submitted

Each file here is a decisions file exactly as the review page (`public/__dev/blank-outliers.html`, written by
`scripts/find-blank-outliers.ts`) produced it and the founder sent it back, named by date and order.
`scripts/apply-blank-decisions.ts` applied them; what each decision became — applied, already so, or put back —
is noted on the station's row in the catalogue file, in words.

The review page reads this folder when it is generated and clears any tick that is already here (same blank,
station, attribute, figure and note, and not touched since that file was generated), so a later submit carries
only new decisions. The app and the seed never read this folder.

006 — Rotate the board in place

The layout does not move. Same sidebar, same viewer panel, same everything — only the board turns, inside the frame it already occupies. The control is the button in the viewer's upper-right corner. Click it.

Settled: vertical is the default, the choice is view state that resets each session, and the button belongs to the Template viewer only — Rails, Fins and Summary do not get one.

The viewer frame here is 990 × 737, measured from the running app at 1440 × 900. It is already landscape at 1.34:1, which is why this works: a vertical board fills its height and wastes the width, so turning it costs nothing and buys length.
